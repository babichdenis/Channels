# MEDIA_POLICY.md

## Правило

### REPOST

Источникное изображение:

- не crop;
- не square;
- не удалять watermark кадрированием;
- не менять композицию;
- не перерисовывать.

Сохранять оригинальный файл.

### GENERATED

Генерируемые изображения:

- не crop;
- не обрезать 8–10% снизу;
- не переводить автоматически в квадрат;
- сохранять aspect ratio, заданный генератором.

Если Telegram не принимает файл:

1. проверить размер;
2. при необходимости пропорционально уменьшить;
3. если это невозможно — отправить пост без изображения;
4. не резать изображение ради прохождения лимита.

Длинный текст (>1024) при картинке/видео: медиа идёт отдельным сообщением
без подписи, полный текст — следующим. Картинку не выкидываем никогда.
Карточка утверждения всегда показывает фото (иначе владелец апрувит вслепую).

Telegram Bot API для `sendPhoto` допускает фото до 10 MB, сумму ширины и высоты до 10000 и ratio до 20.
