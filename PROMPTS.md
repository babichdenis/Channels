# Промпты и конвейер каналов (актуальная версия)

> Этот файл описывает **как система работает сейчас** (скрипты, бот, статусы) и даёт
> промпты для ручной работы. Всё живёт на Mac .2 в `~/channels/`.

## 0. Архитектура

```
ИСТОЧНИКИ                         КОНВЕЙЕР                         УТВЕРЖДЕНИЕ
GitHub Trending (4 среза) ─┐
Hacker News ───────────────┤   conveyor.py --ingest            approval_bot.py
Telegram RU/EN (23 канала) ┤   (сбор + дедуп md5/SimHash)  →   (кнопки в личке)  →  scheduler.py
ручная пересылка боту ─────┘   --adapt N  /  --digest N          ✅ 🗓 ❌ ♻️           (публикация)
```

**Скрипты (`~/channels/`):**

| Скрипт | Что делает | Автозапуск (launchd) |
|---|---|---|
| `conveyor.py` | сбор источников, адаптация, подборки | вручную / по задаче |
| `news_conveyor.py` | новости: ingest → кластеры → адаптация | `com.denis.news-conveyor` (каждые 15 мин) |
| `approval_bot.py` | утверждение постов в личке | `com.denis.approval-bot` (постоянно) |
| `scheduler.py` | публикация по расписанию | `com.denis.channels-scheduler` (постоянно) |
| `gen_images.py` | генерация картинок (pollinations) | вручную |
| `gen_avatars.py` | аватарки каналов | вручную |

**Команды:**

```bash
python3 conveyor.py --ingest                 # собрать посты из источников
python3 conveyor.py --adapt 6 --auto         # 6 постов, модель сама выберет канал
python3 conveyor.py --digest 8 --channel neuro_secrets   # подборка инструментов
python3 news_conveyor.py --ingest --clusters --adapt 3   # новости
python3 scheduler.py --list                  # очередь
python3 scheduler.py --publish-now <id>      # опубликовать сейчас
```

## 1. Каналы и их форматы

| Канал | О чём | Форматы постов |
|---|---|---|
| **Нейро-секреты** (`neuro_secrets`) | нейросети простыми словами: работа, быт, учёба | A «цель → промпт», B «инструмент + алгоритм», C «подборка инструментов», D «разбор новинки» |
| **Волшебные промпты** (`wizard_prompts`) | библиотека промптов: фото, дизайн, тексты | промпт дня (в кавычках), до/после, разбор, подборка |
| **Нейро-Пульс** (`ai_news`) | новости ИИ: что вышло, что умеет, сколько стоит | новость (450–700), разбор (700–950) |

Полные промпты каналов (копируются в любую модель):
`PROMPT_CHANNEL_NEURO_SECRETS.md`, `PROMPT_CHANNEL_WIZARD_PROMPTS.md`.
Новостной промпт встроен в `news_conveyor.py` (`NEWS_SYSTEM`).

## 2. Статусы постов (queue.json)

```
pending → approved → published
        ↘ rejected
```

- `pending` — ждёт утверждения (бот прислал в личку)
- `approved` — одобрен (✅ «сейчас» → время = now+1 мин; 🗓 «в расписание» → свой слот)
- `published` — опубликован (сохранён `message_id`, `published_at`)
- `rejected` — отклонён (❌ или `/delete`)

## 3. Бот утверждения (`approval_bot.py`)

Кнопки под каждым постом:
- **✅ Опубликовать сейчас** — уходит в канал через минуту
- **🗓 В расписание** — остаётся на своём слоте
- **❌ Отклонить** / **♻️ Перегенерировать** (переписывает текст заново)

Команды: `/start` (меню), `/queue`, `/edit <id>`, `/delete <id>`, `/monitoring`.
Пересылка: **пришли/перешли боту любой текст** → выбери канал → получишь черновик.
Уведомления: новые подписчики каналов (счётчик) и участники групп (с именами).
Верификация комментов: группа с «Одобрять новых участников» → бот проверяет подписку на канал
и одобряет/отклоняет заявку.

## 4. Правила достоверности (evergreen + новости)

**Для контентных каналов (вечное):**

| ❌ Запрещено | ✅ Вместо этого |
|---|---|
| «вышла новая модель», «обновили», «только что» | «нейросеть умеет…», «есть приём…» |
| даты, годы, «в этом месяце» | «сегодня», «в любой день» |
| версии (v2, 4.5, Pro), свежие релизы | «нейросеть», «ИИ-помощник» |
| цены, тарифы, акции | без цен |
| статистика, «N пользователей» | без цифр-фактов |

Исключения: **новости** (там бренды и цифры — это суть) и **инструменты в «Секретах»**
(можно имя и официальную ссылку: сайт/GitHub; без партнёрских ссылок и тарифов).

**Для новостного контура (Нейро-Пульс):**
1. Свежесть: только посты **не старше 6 часов** (окно в `news_sources.json`).
2. Подтверждение: минимум **2 независимых источника** (кластеризация по сущностям/терминам).
3. Фильтр ценности (три уровня):
   - предфильтр источника: слухи/«в разработке»/«держат в секрете» — не берём;
   - промпт: пропускаем «невыпущенное», прогнозы без цифр, общеизвестное без нового факта;
   - проверка готового текста: «не выпущена/название неизвестно/слухи» → не публикуем.
4. Публикуем только с конкретикой: что произошло + что умеет / сколько стоит / цифры / доступность.

## 5. Дедуп и качество

- **Точные дубли:** md5-хэш текста (стабильный, между запусками).
- **Похожие тексты:** SimHash 64-бит, порог 10 (одна новость из разных каналов — не берём).
- **Черновики:** проверка против всей очереди (похожее на готовый пост не добавляется).
- **Мусор:** проверка на «поехавший» текст и иероглифы (CJK) → черновик бракуется.
- **Гонки:** конвейеры только **добавляют** посты (`add_to_queue`), не перезаписывая очередь.

## 7. Промпты для ручной работы

### 7.1 Генератор постов (если пишет человек)

```
Ты — контент-редактор Telegram-канала «{{НАЗВАНИЕ}}».

О КАНАЛЕ
- ЦА: {{ЦА}}
- Обещание: {{ОБЕЩАНИЕ}}
- Тон: {{ТОН}}
- Рубрики: {{РУБРИКИ}}

ЖЁСТКИЕ ПРАВИЛА
- Никаких дат, новостей, версий, свежих релизов, цен и статистики.
- Инструменты — по имени, официальные ссылки можно (без партнёрских).
- Не обещать доход, не давать медсоветов, не упоминать политику.
- Каждый пост заканчивается действием: промпт, шаг или вопрос.
- 400–700 знаков, короткие абзацы, 3–5 эмодзи, 2–3 хэштега.

ЗАДАЧА
Напиши {{N}} постов по сетке: {{СЕТКА}}. Темы: {{ТЕМЫ}}.

ФОРМАТ — строго JSON:
[{"day": "Пн", "time": "09:00", "rubric": "Секрет дня", "title": "...",
  "text": "...", "hashtags": ["#секретдня"], "image_prompt": "...", "notes": "..."}]
```

### 7.2 Редактор-фактчекер

```
Ты — строгий редактор Telegram-канала. Проверь черновик.
ЧЕК-ЛИСТ (любой пункт → правь или отклоняй):
1. Есть дата, год, «новый/вышла/обновили/только что»?
2. Есть версии, свежие релизы, бренды в контексте новинок?
3. Есть цены, тарифы, статистика, цифры-факты? (для не-новостей)
4. Есть проверяемые заявления о компаниях/людях?
5. Может ли устареть через месяц?
6. Есть обещание дохода / медсовет / политика?
7. Есть конкретное действие в конце?
ВЫХОД: «✅ OK» + почему, или «❌ ПРАВКИ» + исправленный текст.
```

### 7.3 Генератор картинок

```
Ты — арт-директор канала «{{НАЗВАНИЕ}}».
СТИЛЬ: {{СТИЛЬ_КАНАЛА}}
ТРЕБОВАНИЯ: без текста на картинке; без знаменитостей;
персонажи — славянская внешность, реалистично, без аниме; квадрат/вертикаль; единый стиль.
ФОРМАТ: {"post_id": "...", "image_prompt": "...", "style_tags": [...]}
```

Шаблоны: портрет-акварель · интерьер (скандинавский) · обложка (градиент + искры) ·
аватарка (мягкие черты, светлые волосы) · детская иллюстрация · прикол (кот в костюме).

### 7.4 Планировщик недели

```
Ты — контент-стратег канала «{{НАЗВАНИЕ}}».
Дано: рубрики, сетка (3 поста/день), банк тем, метрики: {{МЕТРИКИ}}.
Собери план: по теме на каждый слот; баланс польза/практика/вовлечение;
усиль лучшие рубрики ({{ЛУЧШИЕ}}); слабые — переупакуй.
ФОРМАТ: таблица «День | Время | Рубрика | Тема | Зачем».
```

### 7.5 Аналитик недели

```
Ты — аналитик Telegram-каналов. Метрики за неделю: {{ДАННЫЕ}}.
Отчёт: ТОП-3 и АНТИ-ТОП-3 постов (почему), рейтинг рубрик по ER и сохранениям,
лучшее время публикации, 5 гипотез на следующую неделю. Коротко, списками.
```
