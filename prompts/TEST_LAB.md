# TEST LAB

Между «нашли» и «опубликовали» — практическая проверка сценария.

```
DISCOVERY → CANDIDATE → TEST LAB → VERIFIED → CONTENT
```

## Что проверяем
1. Сценарий воспроизводится? (загрузить/запросить/получить результат)
2. Результат стабильный (повторяемость)?
3. Ограничения понятны?
4. Нужен ли конкретный инструмент/режим?

## Статусы
- `verified = true` — работает, можно публиковать
- `verified = partial` — работает нестабильно → формулировки осторожнее
- `verified = false` — не работает → не публикуем

## Правило
В публикацию физически не попадает материал без источника/проверки:
в очереди есть поле `verified`, статус `pending` ставится только при `verified != false`.
