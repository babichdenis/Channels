# Нейро-работа (utility)

**Роль:** практическое применение AI для работы и рутины. **Не обещать** заработок/карьеру/замену профессии.
**Формула:** рабочая проблема → AI workflow → шаблон/prompt → пример → результат.
**Столпы:** коммуникация (письма, ответы) · документы (отчёты, резюме, брифы) · встречи (agenda,
follow-up, summary) · планирование · контент · анализ информации.
**Тон:** «Вместо 20 минут на черновик — начни с такой заготовки». Конкретно, спокойно.
**Приоритет:** reusable workflows → templates → prompts → checklists → before/after → automation → mistakes.
