# CONTENT DISCOVERY

Не выдумываем факты про нейросети — находим **реальные сигналы** и превращаем их в seeds.

```
ИНТЕРНЕТ → СБОР СИГНАЛОВ → КЛАСТЕРИЗАЦИЯ → ОТБОР ИДЕЙ → ПРОВЕРКА ИСТОЧНИКА
→ ПРОВЕРКА AI-СЦЕНАРИЯ → НАШ УГОЛ → CONTENT SEED → ПОСТ
```

## Источник ≠ материал
Пост на Reddit «загрузил фото рабочего стола в ChatGPT и попросил организовать» — это не пост,
а **сигнал**: человек → реальная проблема → использовал AI → получил результат.

Извлекаем: `{problem, ai_use_case, action, evidence_type, source, source_url, potential}`.

## Классы источников
| Источник | Что извлекаем |
|---|---|
| Reddit (если доступен) | реальные use cases |
| Telegram | тренды, формулировки, форматы (**не истина**) |
| VK | русскоязычный consumer-сигнал (искать «как сделать…», а не «нейросети») |
| Яндекс.Директ / Wordstat | поисковый спрос (что хотят сделать) |
| Telemetr | популярность: CONTENT PATTERN, а не пост для копирования |
| Официальные блоги AI (OpenAI, Anthropic, Google, HF) | **фактическая проверка возможностей** |
| Документация | проверка, что функция существует |

## 5 типов Discovery Query (искать проблемы, а не «AI»)
- **USER PROBLEM:** «how do I», «any way to», «how can I»
- **USER WORKFLOW:** «I use ChatGPT to», «my AI workflow», «how I use AI»
- **USER DISCOVERY:** «I just discovered», «didn't know ChatGPT could»
- **USER PAIN:** «ChatGPT is bad at», «why does AI»
- **USER RESULT:** «this saved me», «I stopped doing»

## Demand Triangle
```
РЕАЛЬНЫЕ ЛЮДИ ▲
ПОИСКОВЫЙ СПРОС ◄──┼──► СОЦИАЛЬНЫЙ ТРЕНД
AI ВОЗМОЖНОСТЬ ▼
```
Контент появляется только на пересечении: спрос + реальный кейс + проверенная возможность.
