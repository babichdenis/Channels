# DEMAND ENGINE

Сопоставляем три вещи:
```
ПОИСКОВЫЙ СПРОС (Wordstat/Директ)
+ СОЦИАЛЬНЫЙ ТРЕНД (Telegram/VK/Reddit)
+ РЕАЛЬНАЯ AI-ВОЗМОЖНОСТЬ (официальные источники/тест)
= СИЛЬНЫЙ CONTENT SEED
```

## Scoring кандидата (не одна цифра, а дерево решений)
```json
{"interest": 0, "usefulness": 0, "novelty": 0, "evidence": 0, "audience_fit": 0,
 "visual_potential": 0, "prompt_potential": 0, "shareability": 0, "evergreen": 0,
 "verification_difficulty": 0}
```

**Шаг 1. Интересно?**
- «ChatGPT пишет список покупок» — банально → нет
- «Загрузил фото холодильника → AI предложил блюда» — интересно
- «Люди массово используют X, но никто не показывает простой способ» — очень интересно

**Шаг 2. Доказуемо?**
Найти описание способа → официальное подтверждение → воспроизвести → проверить ограничения → только потом пост.

## Локализация зарубежного
```
SOURCE → TRANSLATE → UNDERSTAND → VERIFY → LOCALIZE → ADD OUR VALUE
```
Переносим **механику** («AI планирует семейный праздник»), а не копируем публикацию
(«Thanksgiving dinner» → «семейный праздник: меню, покупки, подготовка»).
