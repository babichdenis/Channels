# CHANNEL MODULES (Level-2 контекст)

> Подключается поверх `00_GLOBAL_RULES.md`. Для каждого канала — свой модуль.
> Машиночитаемые параметры — в `config/CHANNELS.json`.

## Нейро-секреты (flagship)

**Роль:** показать женщине, что нейросети незаметно упрощают обычную жизнь.
**Эмоция:** «Ого, а я могла делать так всё это время».
**Не быть:** техно-каналом, новостным, для программистов, энциклопедией, коллекцией промптов.

**Формула:** маленькая проблема + неочевидное применение AI + готовое решение = секрет.

**Рубрики:** 🔮 Секрет дня (проблема → неочевидный способ → пример → вывод) · 🪄 Промпт дня
(задача → промпт → как использовать) · ✨ До/после (трансформация текста/фото/идеи/плана) ·
🏡 Нейро-лайфхак · 😂 Прикол (юмор + возможности AI) · 🗳 Интерактив · 🧠 Разбор.

**Типы постов:** short_tip, prompt, before_after, checklist, mini_guide, comparison, interactive,
humor, experiment, case, mistake_fix, hidden_feature, workflow. **Не** одинаковая структура у всех.

**Hooks:** «Вот что можно попросить у нейросети вместо...» · «Мало кто использует AI вот так...» ·
«Если вы обычно делаете это вручную...» · «Есть маленький трюк...» · «Вот где AI неожиданно полезен...».
**Избегать:** «Вы не поверите!!!», «ШОК!!!», «Срочно всем!», «Невероятный заработок!».

**Границы:** визуальный стиль → Нейро-образ · коллекции промптов → Волшебные промпты ·
рабочие процессы → Нейро-работа · чистый юмор → Нейро-приколы.

**Visual DNA:** soft lifestyle + AI magic + clean composition + pastel atmosphere.

**Критерий успеха:** «Полезно» / «Надо сохранить» / «Попробую» / «Почему я раньше так не делала?» /
«Отправлю подруге».

## Волшебные промпты (library)

**Роль:** библиотека готовых решений. Не «советы по AI», а «скопируй, вставь, получи результат».
**Формула:** задача → контекст → промпт → пример → ожидаемый результат.
**Качество промпта:** роль, задача, контекст, ограничения, формат результата, критерии качества.
Простые промпты предпочтительнее сложных.
**Категории:** тексты · работа · быт · фото · контент · семья. Высокорисковые (медицина/диагностика) — нельзя.
**Metadata:** prompt_id, category, subcategory, difficulty, use_case, expected_result, reusability, novelty.
**Серии:** «10 промптов для...», «AI-набор для...» — каждый элемент самостоятелен.
**Монетизация:** evergreen prompt packs, коллекции, большие наборы, workflow, шаблоны.

## Нейро-образ (visual)

**Роль:** визуальное применение AI — аватарки, портреты, образы, стиль, moodboards.
**Формула:** idea → visual concept → prompt → image → variations.
**Visual DNA (поля):** subject, environment, composition, lighting, mood, style, camera_language,
color_direction, detail_level. **Не повторять** одну позу/фон/композицию/свет/ракурс.
**Персонажи:** не задавать этничность без необходимости; если важно — нейтрально и конкретно.
**Типы:** prompt showcase, before/after, style transformation, photo concept, avatar idea,
outfit concept, moodboard, social media visual.

## Нейро-работа (utility)

**Роль:** практическое применение AI для работы и рутины. **Не обещать** заработок/карьеру/замену профессии.
**Формула:** рабочая проблема → AI workflow → шаблон/prompt → пример → результат.
**Столпы:** коммуникация (письма, ответы) · документы (отчёты, резюме, брифы) · встречи (agenda,
follow-up, summary) · планирование · контент · анализ информации.
**Тон:** «Вместо 20 минут на черновик — начни с такой заготовки». Конкретно, спокойно.
**Приоритет:** reusable workflows → templates → prompts → checklists → before/after → automation → mistakes.

## Нейро-приколы (reach)

**Роль:** лёгкий пересылаемый контент + демонстрация возможностей AI.
**Формула:** юмор + узнаваемая ситуация + AI twist = shareable.
**Типы:** AI memes, absurd scenarios, funny prompts, unexpected transformations, «а что если...».
**Нельзя:** обычный мемник без AI, политика, токсичность, картинки без идеи.
**Виральные заходы:** «Попросила нейросеть...», «Когда решила делегировать это AI...»,
«Нейросеть поняла задачу слишком буквально».
**Воронка:** attention → share → discovery → interest → полезный канал. Без перегруза рекламой.
